## M&A Deal Screening Tool 

A streamlined M&A screening dashboard built with Streamlit.  
This tool uses real-time financial data from Yahoo Finance to evaluate potential acquisitions, model synergies, test financing mixes, and generate a full Excel output of the deal analysis.

## 🚀 Features
- Live financial data pulled automatically from Yahoo Finance
- EPS accretion/dilution modeling
- Pro‑forma leverage and capital structure impact
- Synergy run‑rate and NPV modeling
- DCF valuation vs. offer price
- Bull/Base/Bear scenario analysis
- Premium sensitivity table
- Financing mix heatmap
- One‑click Excel export with all model outputs

## 🧠 How It Works
1. Enter buyer and target ticker symbols  
2. Adjust deal assumptions (premium, financing mix, tax rate)  
3. Set synergy assumptions  
4. Click **Run Deal Analysis**  
5. View KPIs, scenarios, sensitivities, and verdict  
6. Export everything to Excel
